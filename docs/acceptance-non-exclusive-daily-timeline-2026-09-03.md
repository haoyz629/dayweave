# 非独占日程时间线验收基线（2026-09-03）

> 状态：待实施。上位决策为 `adr/0003-adopt-non-exclusive-daily-timeline.md`。本清单中的项目只有在代码、SQLite 断言和桌面视觉验证完成后才能勾选。
>
> 本清单中的“排程、占用、阻塞/不阻塞、午休、缓冲”等旧词，仅用于指出应删除的旧能力、验证历史数据兼容或区分执行结果；它们不是现行界面术语。2026-09-01 及更早验收记录作为历史快照保留原文。

> 后续取代范围：本清单保留原状态与勾选，不伪造重新验收。下文“自动安排”只保留非独占规则的历史验证语境，不再要求提供生成／重新排程入口；安排流程以 `adr/0005-single-day-direct-scheduling.md` 为准：单日正式保存事务内直接安排，日常加入／移除／调时立即保存可撤销，已有整批草案仅改草案并保留整批确认。历史、执行、复盘保护及多块例外同依 ADR-0005。

## SQLite 与领域规则

- [ ] 同一日期、相同起止时间的多个任务块可以在一个事务中全部写入，SQLite 行数和每条起止时间正确。
- [ ] 部分交叠、包含交叠和链式交叠的任务块都能保存，不需要例外确认。
- [ ] 固定日程与任务块重叠时两者都保留，固定日程不会被 AI 移动或改写。
- [ ] 已确认任务块不会阻止后续草案或计划块写入相同时段。
- [ ] 工作时间外和未选工作日可以创建、编辑、确认和调整时间块，不产生“计划外”事实。
- [ ] 历史午休与缓冲列可以安全读取，但不参与候选时间、校验、草案失效或保存结果。
- [ ] 删除或停用冲突判断后，任务最早开始、截止边界、正时长、日期归属和任务状态校验仍然有效。
- [ ] 已安排分钟仍按任务累计已确认且未进入最终复盘的执行块工作量，避免同一任务跨日重复分配；它不参与时段独占判断。
- [ ] 所有确认和撤销继续保持原子事务，失败时 SQLite 不出现部分写入。

## 自动安排

- [ ] 已有固定日程、执行块、草案块和重复事项不会从候选时间中扣除。
- [ ] 自动安排可以优先使用工作日和工作时间，但工作时间外结果合法且可确认。
- [ ] 自动安排允许生成重叠事项；错开只是一种可读性偏好，不是有效性条件。
- [ ] “未安排”原因不再包含时间不足、空档不足、固定日程冲突、任务块重叠、午休或工作时间外。
- [ ] 缺少预计工作量、任务不在日期边界内或任务状态不再可安排等真实原因仍清楚显示。

## 重叠布局

- [ ] 起止时间完全相同的 2、3、4 个事项横向等分，宽度一致且无内容覆盖。
- [ ] 起止时间不同但相交的事项形成完整耦合组，纵向位置与真实时间一致，并稳定分列。
- [ ] 同起点、不同结束时间的事项按结束时间降序分列，较长事项成为左侧锚点；完全同起止事项使用稳定对象键打破平局。
- [ ] 时间包含表现为同一画布中的并列矩形，不使用 DOM 嵌套、视觉内缩、背景包裹或连接线暗示父子关系。
- [ ] 包含、部分交叠、链式交叠和结束后复用空列均有确定性测试。
- [ ] 耦合组只在局部达到三列时，处于其他时段且右侧无碰撞的事项可以安全扩展，不会无谓保持三分之一宽。
- [ ] 横向扩展只从稳定基础列向右发生，宽度在事项整个高度内保持不变，不产生向左跳动或 L 形事项块。
- [ ] 上午与下午等互不连接的耦合组独立计算列数；单独事项恢复全宽。
- [ ] 相邻但不重叠的事项（前一项结束等于后一项开始）可以复用同一列。
- [ ] 极短相邻事项因视觉最小高度发生绘制碰撞时可以临时分列，但时间文案、数据和领域语义仍使用真实区间。
- [ ] 视觉最小高度不会造成卡片互相遮挡；输入数组换序、重新读取或刷新后列顺序不随机变化。
- [ ] 固定日程、执行块、日计划草案块和有展示时间的重复事项使用同一布局函数；对象类型不决定列优先级。
- [ ] 多列窄卡优先保留对象标识、标题和时间，完整信息可通过鼠标悬停与键盘聚焦读取。
- [ ] 当前时间线始终覆盖在非工作时间背景和事项卡片之上。

## 普通任务执行块

- [ ] 使用左侧细状态线、紧凑标题/时间层级和低对比度纸面。
- [ ] 圆形勾选框固定在标题左上方、标题之前，并在窄列中保持可见和可聚焦。
- [ ] 勾选框与内容区是两个独立点击和键盘目标；操作一个不会误触另一个。
- [ ] 勾选只完成本次执行块，不完成长期任务。
- [ ] 最终复盘前可以取消勾选并清除本次轻量执行记录；最终复盘后锁定并说明原因。
- [ ] 第二行使用时钟图标和统一 `起 - 止` 时间格式；结果状态不只依赖颜色。

## 日计划草案块

- [ ] 与普通执行块共享左侧细状态线、标题和时间层级，但不显示执行勾选框。
- [ ] 草案与正式执行块在纸面、边框和文字上可区分；确认前不表达已经写入日计划。
- [ ] 点击与键盘操作都能调整时间，重叠不会阻止保存草案。

## 重复事项块

- [ ] 重复事项仍是独立规则和按日发生记录，不生成普通任务或执行块。
- [ ] 有展示时间的重复事项与固定日程、草案块和执行块进入同一个重叠布局。
- [ ] 卡片右上角保留重复/刷新图标，不显示普通任务勾选框，也不显示“不阻塞”文字。
- [ ] 重复事项默认不打开详情弹窗；悬浮与键盘聚焦说明包含类型、标题、时间和当日结果。
- [ ] 无展示时间的重复事项继续显示在时间线顶部区域。

## 设置与非工作时间

- [ ] 设置页删除午休、不可安排时段、原因和任务间缓冲控件及相关未保存状态。
- [ ] 工作日和每日工作时间文案明确说明“用于安排偏好和时间线参照，不限制手动安排”。
- [ ] 非工作日和工作时间外使用小时网格底层的极浅中性背景，不渲染成事件卡片。
- [ ] 非工作时间背景没有圆角边框、大段重复文字或独立焦点目标；屏幕阅读器仍能获得工作时间说明。
