# 任务编辑器与时间范围验收基线

## 1. 范围与原型解释

本基线覆盖任务页、任务时间范围、任务胶囊、回收站操作和今日时间线调整相关的前端变化。紧凑宽度与宽窗口使用同一个任务页右侧检查器，由可用宽度自动选择布局；不创建独立路由、编辑模式或“全屏编辑”入口。设计参考文件仅保留在本地，不是验收本基线的前提。

## 2. 任务页与编辑器

| 场景 | 验收结果 |
|---|---|
| 点击任务 | 在当前任务页检查器中直接打开，不跳转独立页面 |
| 普通检查器 | 使用紧凑单列或局部双列，正文独立滚动 |
| 检查器 ≥960px | “任务内容 / 安排与时限”按约 7/5 双栏展开 |
| 检查器 ≤560px | 日期卡片、属性区和底部操作统一单列 |
| 内容分区 | “任务内容”“安排与时限”为独立小标题；标题和备注各有明确字段名 |
| 新建普通任务 | 按“任务标题 → 安排与时限 → 备注”显示；既有任务编辑页保留原顺序 |
| 新建重复事项 | 按“事项标题 → 重复安排 → 备注”显示；备注按钮点击展开，收起时保留内容，已有备注的草稿重新打开后可见 |
| 创建草稿保存 | 实际编辑字段后延迟自动保存；仅切换任务类型不自动保存，离开当前胶囊前保存已有待保存内容 |
| 顶部操作 | 不显示重复的右上角关闭按钮 |
| 底部操作 | “完成整个任务 / 移入回收站”和“取消 / 保存修改”分组 |
| 取消 | 关闭当前编辑状态并保留当前任务列表页 |
| 移入回收站 | 状态更新后留在当前页面，不自动切换回收站 |

## 3. 完整时间范围选择器

- 一次编辑开始日期、开始时刻、结束日期和结束时刻；顶部边界卡片控制当前编辑端，左侧月历选择日期，右侧共享双端时间轴。
- 时间手写接受 `1`、`100`、`01:00`、`7:5` 等短格式，规范化后保持 1 分钟精度；非法输入显示 `00:00–23:59` 约束。
- `Enter` 提交当前时间输入；输入框内 `Esc` 恢复选择器当前值并退出该输入，不关闭整个弹层。取消、点击遮罩和选择器级 `Esc` 均不提交。
- 同日起止最短相隔 15 分钟，并显示 15、30、60、120 分钟快捷项；跨日不显示快捷时长。
- “清除时间”清空四项边界；“恢复推荐”恢复下一整点至一小时后的默认范围。两种状态在中等宽度均保持双列属性占位，≤560px 均为单列，宽屏双栏编辑器中的属性区也保持稳定。
- 正式任务仍必须具有完整且有效的四项边界；清除时间不能绕过前端、领域和 SQLite 约束。

## 4. 工作量语义

| 时间状态 | 编辑器表现 | 数据语义 |
|---|---|---|
| 同日且完整 | 标题行显示“预计投入 X 小时 / 自动计算”，无独立输入 | 等于结束与开始的分钟差 |
| 跨日且完整 | 输入平均每日投入并展示总投入 | 总投入 = 包含首尾日期的自然日数 × 平均每日投入 |
| 时间不完整的草稿 | 显示预计总投入输入 | 仅作为草稿信息，不使其成为正式任务 |
| 历史跨日值不能整除 | 不反推平均值 | 保留原总投入，等待用户明确填写 |

## 5. 双端时间轴

- 开始端点为空心，结束端点为实心；两者大小一致并垂直居中于轨道。选中背景连续包裹两端，中间显示 `1h`、`5h 10m` 等紧凑时长。
- 拖动和方向键以 5 分钟为步进，手写仍可精确到 1 分钟；最短范围为 15 分钟。
- 15 分钟短范围保留真实端点位置，不在释放后强制弹开；命中距离和最近端点判定保证两端可独立抓取。
- 连续时间轴每小时显示一个刻度；刻度与起止范围文字重叠时隐藏，端点移开后恢复。拖动期间复用当前展示窗口，避免刻度、端点和按钮位置抖动。
- 不超过四小时使用连续时间轴；超过四小时切换断轴。断轴左右保留开始、结束附近的可操作窗口，中间展示总时长，省略区不可拖动。
- 连续/断轴切换安全重建展示窗口；01:00–23:00 等超长范围不得崩溃。断轴端点卡片悬停显示 `grab`，拖动期间保持 `grabbing`。
- 亮色和深色模式均清楚区分未选轨道、选中背景、端点与断轴边界；断轴轨道不使用多余底部阴影。

## 6. 状态、优先级与任务胶囊

- 全局状态色：草稿/未确认=琥珀，待处理=蓝，已安排=靛蓝，已完成/生效中=绿，回收站/已结束=玫瑰红，重复事项类型=紫。
- 优先级色：低=蓝，中=琥珀，高=红。优先级选择器使用状态点、浅色背景、细边框和自绘箭头，同时保留原生选择语义。
- 所有状态同时显示文字以及圆点或图标，颜色不是唯一信息来源；深色模式使用独立映射。
- 任务胶囊标题始终单行省略，并通过标题提示或详情保留完整内容；备注为单行摘要。
- 重复事项胶囊第一行事实为截止日期或长期有效；第二行为重复频率及可选展示时间，不在时间值后附加“时间”二字。“频率”“时长”标签保持正常字距。
- 今日页待安排胶囊使用自然高度，说明和元数据不得被固定高度裁切。时间线执行块允许内容安全收缩，勾选控件不得遮挡标题。
- 胶囊悬停操作只在 hover 或真正的 `focus-visible` 时显示；普通鼠标点击后的焦点不应让操作长期常驻。

## 7. 回收站与今日时间线

- 普通任务只有“完成”和“移入回收站”两条结束路径，不提供“不再进行”。
- 回收站胶囊在悬停或键盘聚焦时显示恢复和永久删除图标；永久删除必须再次确认。
- 回收站详情顶部固定提示条，按分钟显示已移入时长与距离 30 天永久删除的剩余时间；重复事项进入回收站后保留历史。
- 已确认计划不提供单独“调整计划”模式。首次实际改动执行块或加入待安排任务时自动建立调整草案；仅打开后取消不留下空草案。
- 新加入的任务块自动滚动到可视区，并遵循 `prefers-reduced-motion`。
- 任务块主体打开执行详情，勾选按钮只负责快速完成；详情浮层就近避让，窄窗使用底部样式。
- 从任务块进入任务页后提供“返回任务块”，时间调整面板提供“返回任务块详情”。“从今日计划移除”位于详情/调整流程；执行备注只在选择结果后出现。

## 8. 自动化契约

相关测试：

```powershell
npm run test:ui-copy
npm run test:create-type-switch
npm run test:task-workload
npm run test:rust
node --test src\time-range-control.test.mjs
npm run build
git diff --check
```

`src/ui-copy.test.mjs` 覆盖完整时间选择器、内联响应式检查器、工作量文案与布局稳定、状态色、回收行为、任务胶囊和今日时间线返回/滚动流程。`src/time-range-control.test.mjs` 覆盖短格式输入、15 分钟边界、端点独立抓取、稳定展示窗口、四小时切换、小时刻度避让与超长断轴。

## 9. 人工复核矩阵

自动化测试不能替代以下视觉复核：

1. 分别在紧凑、小窗、普通桌面和最大化宽度打开同一任务，确认无独立页面跳转且操作不被裁切。
2. 在亮色/深色模式检查所有状态色、优先级色、连续轨道和断轴底色。
3. 分别拖动 15 分钟、1 小时、4 小时和 01:00–23:00 范围，确认无弹开、抖动、换窗崩溃或光标丢失。
4. 点击清除时间和恢复推荐，确认任务检查器宽高与属性列不跳变。
5. 以窄分栏打开长标题、长备注的待安排胶囊与执行块，确认标题省略、信息可见且勾选不遮挡。
