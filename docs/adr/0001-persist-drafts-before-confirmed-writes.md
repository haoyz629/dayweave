# 在确认写入前持久化独立草案

手动创建与 AI 创建共用同一种任务草案和增强表单，草案自动保存到独立持久化模型，但不会提前进入正式任务表。用户只能逐条确认；确认后通过幂等的 Rust/SQLite 事务生成正式任务。关于确认所需的完整时间与已移除的 Inbox 语义，以 ADR-0004 为准。

## Consequences

- 任务页必须提供独立“草案”入口，并区分 AI 草案与手动草案。
- 任务来源在首次确认创建时确定为 `ai_assistant` 或 `manual`。
- 对话归档不删除关联草案；永久删除对话前必须处理关联草案。
- 同一确认令牌只能消费一次，重试和双击不得创建重复任务。
