# 在确认写入前持久化独立草案

手动创建与 AI 创建共用同一种任务草案和增强表单，草案自动保存到独立持久化模型，但不会提前进入正式任务表。用户只能逐条确认；确认后通过幂等的 Rust/SQLite 事务生成正式任务，无日期任务进入 Inbox。这样既能恢复未完成输入，也能避免把未确认的 AI 结果或空白手动任务伪装成真实任务。

## Consequences

- 任务页必须提供独立“草案”入口，并区分 AI 草案与手动草案。
- 任务来源在首次确认创建时确定为 `ai_assistant` 或 `manual`。
- 对话归档不删除关联草案；永久删除对话前必须处理关联草案。
- 同一确认令牌只能消费一次，重试和双击不得创建重复任务。
