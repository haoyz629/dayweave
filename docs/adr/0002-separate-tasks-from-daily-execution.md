# 将任务生命周期与每日执行分开

> 2026-09-03 修订：`0003-adopt-non-exclusive-daily-timeline.md` 取消了执行块对钟表时段的独占语义，但不改变本 ADR 的任务、执行与复盘分离边界。

任务日期、任务完成、日计划和执行块是不同事实：日期只是约束，确认日计划才产生具体执行块；执行块表达希望执行的时段，可以与其他事项重叠。完成一个执行块也不会自动完成长期任务。长期任务记录总工作量、累计实际耗时与可重新估算的剩余工作量，只有用户明确确认才改变任务完成状态。

## Consequences

- 日期必须允许只有日期而没有具体时刻，AI 不得补造时刻。
- 晚间复盘记录执行结果和实际耗时，但不覆盖原截止日期或原计划事实。
- 早间计划持续考虑未明确完成的长期任务，并按剩余工作量分配执行块。
- 重复任务生成独立实例，只支持“修改本次”和“修改本次及以后”。
