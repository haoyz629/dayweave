# 轻量执行记录、可靠草稿与最近 7 天补录

> 2026-11-28 取代说明：v2 架构已由 `0008-unified-mica-workbench-and-three-mode-scheduling.md` 取代本 ADR；独立复盘记录、复盘表单草稿与 7 天补录机制已从前后端移除，改为就地标记完成、子任务勾选与重复按日快照。下文保留为历史决策记录。

## Context

普通事务与长期分段任务原先承担近似的复盘成本：先记录本次结果，再填写耗时确认复盘，再确认整件任务结束。结果与耗时数据虽可保护历史，但并非每次填写都会改变下一步安排。原页面保存一条会重建其他未提交表单，增加了不必要的输入损失。

## Decision

### 导航与默认成本

- 一级仅今日、任务、设置；今日常驻二级切换“日程｜复盘与记录”，默认日程，日程内月历／时间线不变。
- 两个视图共享所选日期，记录视图仍高亮今日，再点一级今日返回日程。旧复盘跳转归一到今日记录；已有计划草案与记录草稿继续有离开保护。
- 记录按需处理／已记录分组，正常轻量结果已有效，不要求再确认完整复盘；不新增全局复盘红点或每日填写率目标。
- 耗时、剩余量、原因和备注按需展开补充。实际耗时 NULL 为未知，0 为明确的零投入，不默认用计划时长；只累计明确填写的值，不按耗时自动扣减剩余量。

### 整项完成与重复结果

- 勾选仍只表示本次执行完成。明确点击“完成整个任务”不以复盘和耗时为前提，不再叠加第二层确认表。
- 同一事务保存所选今天块结果、任务 done、剩余量 0 和变更／估算历史。任务页无指定块时选择今天最早块，没有今天块也可完成；已有最终复盘保持原样，其他块不删除、不伪造完成。
- 整项完成提供 10 秒安全撤销，快照指纹校验后续任务、执行、复盘、删除等变化；撤销通过补偿记录恢复本次变化，不清除原历史。
- 重复事项点击结果即保存，备注可选并明确保存，提供同样的短时安全撤销；规则不变，不生成普通任务、不新增跳过状态。

### 草稿与关闭

- SQLite 表 `review_form_drafts` 按日期、task／recurring 类型及块／发生记录 ID 保存未提交表单。
- 输入防抖写入，以串行队列和 CAS 版本防止覆盖。切日期、视图、页面与正常窗口关闭前等待保存，失败留在输入处重试；自动草稿不产生正式事实。
- 正式保存仅清理对应草稿，保留单调递增版本墓碑防止迟到保存复活。刷新按条目合并，不覆盖其他已编辑内容。
- 日程中的轻量结果保存不代表提交补充详情：保留未提交耗时、原因、长备注和剩余量，去除草稿中已被新结果取代的结果选择并推进版本；旧自动保存仍被拒绝。已删除重复事项仅展示历史，不生成可编辑表单。
- 记录视图原生关闭通过事件等待前端保存后再按已有设置关闭／隐藏；其他页面关闭语义保持不变。强杀进程不承诺保存未完成的防抖输入。

### 七天窗口与历史事实

- 按中国标准时间，今天及此前 6 天允许对已有对象首次补录；不事后新建历史日计划或重复发生记录。
- 历史轻量结果尚无最终补充记录时，可以首次补充详情；已确认详细记录不覆盖。历史重复结果首次保存后只读。
- 历史只补结果、耗时、原因和备注，不修改当前剩余量、任务状态、日期或安排；后端拒绝历史非空剩余量输入。已知耗时可以追加累计投入。
- 发生日期保持原值，created_at 为真实保存时间。更早和未来不可写，未来有回到今天操作。
- 没有执行结果时仍是未知，不自动完成、延期或补造工时。

## Compatibility

迁移 v22 允许复盘耗时为空，保留旧数据、主键关联、外键、索引及触发器；不重算已有累计值、不把空转成 0、不自动完成旧任务。旧整项完成 API 保留兼容入口但不再要求复盘／额外确认标记，历史日期不可用于完成当前任务。旧冻结方案冲突条款仅作历史上下文。
