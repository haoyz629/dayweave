# 统一浅色云母工作台与三态任务调度模型（v2 架构）

## Context

在早期 v1 架构中，系统同时维护了任务（`tasks`）、任务草案、每日计划草案（`daily_plans`）、执行块（`plan_blocks`）、固定日程（`calendar_events`）、复盘记录（`review_entries` / `review_form_drafts`）、变更历史以及 AI 对话与运行记录（`ai_*`）等多套概念与表结构。随着日常个人使用实践的收敛，这套模型暴露出明显的心智与交互负担：

- 用户仅为一件待办留出时间，需要理解“任务日期约束 / 日计划 / 执行块 / 复盘结果”多层状态；
- 强制要求正式任务必须填全起止日期与时刻（ADR-0004），使尚未决定具体时段的待办只能滞留在草稿中，无法自然形成待安排池；
- AI 助手浮窗、独立复盘表单与周视图增加了界面与维护复杂度，但当前个人本地工作台的核心诉求已聚焦为“快录待办 → 编织入日历 → 就地完成 → 规则重复”。

因此，本轮改版对产品信息架构、领域模型、SQLite 数据层和前端工作台进行了整体重构，确立面向 Windows 浅色云母体验的统一 v2 工作台架构。

## Decision

### 1. 三态任务调度模型（`pool` / `flex` / `timeline`）

用单一 `tasks` 实体配合 `mode` 字段替代原先分离的任务、执行块与固定日程模型：

- **`pool`（待安排）**：已成立的正式任务，只需标题即可存在（可附带预计耗时、优先级、标签、备注与子任务），停留在工作台左侧待安排池中，随时可一键「排入」或拖拽至时间轴与日历日期。
- **`flex`（全天 / 多日弹性）**：绑定单个日期或连续日期范围（`date_start` 至 `date_end`），不占据具体钟表时段，置顶展示于工作台「全天 / 多日」区，并在月视图中以跨日条呈现。
- **`timeline`（已排入时间轴）**：绑定具体日期（`date`）、开始分钟（`start_min`）与持续时长（`duration`，最短 15 分钟），直接呈现在 24 小时非独占日时间线上，并触发桌面定时提醒。

同步引入轻量**子任务（`task_subtasks`）**，支持在任务详情抽屉中逐项拆解与勾选，并在日时间线任务块上展示子任务进度与「下一步」预览。

### 2. 简化标签、优先级与独立草稿箱

- **标签（`tags`）**：每个任务、草稿或重复规则最多绑定 1 个彩色标签（蓝 / 靛紫 / 翠绿 / 琥珀 / 玫红 5 色），时间块与月历卡片颜色自动随标签同步；系统至少保留 1 个标签，删除标签时事务性清空关联引用。
- **优先级（`priority`）**：收敛为 3 档——普通（空）、`P1`（紧急）、`P2`（重要）。
- **草稿箱（`drafts`）**：与正式任务分离存储；开启「弹窗关闭自动暂存草稿」时，关闭未提交的新建弹窗会自动写入草稿箱，从草稿箱恢复并提交时在同一 SQLite 事务内创建正式任务并移除草稿。

### 3. 保留核心基础能力与历史事实边界

- **非独占 24 小时时间轴（延续 ADR-0003）**：多个任务块与定时重复事项可以在同一时段并列排布，采用连通分量等宽分列（`layoutOverlappingItems`），不因时间重叠阻止创建或移动。
- **重复规则与按日快照（`recurring_rules` / `recurring_occurrences`）**：支持每天、法定工作日、每周多选、每月固定日 4 种频率，支持时间轴或全天弹性两种形态；发生记录以 `record_json` 持久化快照。在时间轴拖动调整重复事项时，明确询问作用域：
  - **仅调整本次**：仅覆盖当日发生记录的时间/时长；
  - **调整本次及未来安排**：在同一事务内先将早于目标日期（最多回溯 366 天）的未记录历史日期按旧时间冻结快照，再原地更新单一规则，确保历史日期不漂移、规则不重复分裂。
  - 暂停、编辑或归档规则均保留已完成或已记录的历史快照。
- **30 天软删除回收站**：移入回收站的任务保留 30 天，启动时自动清理到期记录，支持随时恢复、单条彻底删除与清空回收站（均经确认对话框保护）。
- **本地离线与 Windows 桌面集成**：延续 Tauri v2 + SQLite 事务真理、WinRT 原生开始前/结束前提醒（含「打开今序 / 快捷完成 / 稍后提醒 / 我知道了」交互）、系统托盘、单实例保护、开机启动与内置 + jsDelivr 法定节假日同步。
- **关键操作 10 秒撤销**：任务完成切换、排入时间轴、移回待安排、移入回收站、跳过当日重复及单次重复调时提供 10 秒白卡撤销条（支持 `Ctrl+Z`）。

### 4. 移除范围与界面架构

- 前后端完整移除 AI 助手、AI 连接/API Key 配置、独立复盘工作流（7 天补录与复盘表单草稿）、固定日程实体以及周视图。
- 应用壳升级为 Win11 Fluent 浅色云母工作台：`48px` 半透明集成标题栏（含居中智能快录栏与 `[日 | 月]` 视图切换）、`56px` 左侧图标导航栏（日程 / 全部任务 / 草稿箱抽屉 / 重复规则 / 回收站 / 设置）、`318px` 自适应工作台左栏、`360px` 右滑任务详情抽屉与 `336px` 左滑草稿箱抽屉。

### 5. SQLite 架构升级与旧库保护

- 数据库升级至 `PRAGMA user_version = 3`（核心表：`tags`、`tasks`、`task_subtasks`、`drafts`、`recurring_rules`、`recurring_occurrences`、`ui_settings`、`holiday_calendar_years`、`holiday_calendar_metadata`、`task_reminder_sent`、`task_reminder_snoozes`）。
- 启动打开已有数据库时，若检测到 `user_version < 2` 且存在旧表，先将旧库重命名备份为 `dayweave.v1.bak.sqlite3`（如已存在则追加时间戳），再初始化干净的新版结构，确保旧数据不会静默丢失。

## Consequences

- 领域模型与 UI 概念大幅收敛，用户无需区分“任务 vs 执行块”或“日计划草案 vs 正式计划”，创建、编织与调整链路更直接。
- `ADR-0002`、`ADR-0004`、`ADR-0005`、`ADR-0007` 及其配套验收文档转为历史决策记录保留在仓库中；`ADR-0003` 的非独占时间轴原则继续生效，其余细节以本 ADR 与当前代码为准。
- 当前版本继续仅开发与验收浅色模式（暗色模式暂缓）。
