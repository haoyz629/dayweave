# 法定节假日数据来源与维护

## 实际在线数据源

客户端直接使用 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 经 jsDelivr 分发的年度 JSON：

```text
https://cdn.jsdelivr.net/gh/NateScarlet/holiday-cn@master/{year}.json
```

`{year}` 必须替换为具体数字，例如 `2026.json`。不请求字面量 `{year}.json`，不请求 `index.json`，也不依赖本仓库公开或自有分发服务。此前配置的自有仓库路径未经确认且不可用，现已移除。

这是第三方整理数据，不是政府官方接口。上游说明其根据国务院公告自动更新，`papers` 提供政府通知链接；事实仍以正式公告为准。上游使用 [MIT 许可证](https://github.com/NateScarlet/holiday-cn/blob/master/LICENSE)。客户端仅下载公共日历文件，不上传任务、日程或个人设置。

## 下载与内部格式

- 按年份下载 `year`、`papers`、`days`；`days[].isOffDay=true` 为休息日，`false` 为补班日。未列出的日期按正常周一至周五工作、周末休息处理，不能一律视为工作日。
- 校验公告年份、政府 HTTPS 来源、日期格式、名称、布尔值及日期唯一性；非法数据不安装。`$schema` / `$id` 仅作为元信息，不会据此访问其他主机。
- 默认检查当前年度、次年度、已有缓存年度及用户请求年度，补查两端之间的中间年份，不能跨过缺失年份推算法定工作日重复次数。
- 上游年份按公告标题归属，次年公告可能含上一年 12 月的安排。因此同时读取末端的下一年度文件，将相关日期归入实际自然年；同一日期以次年文件为准。只有次年文件中的跨年日期，不足以证明上一整年已有覆盖。
- 若相邻文件暂时 404，保留已缓存的 12 月例外日期；完整的新相邻文件到达后再据其重新计算。本年文件 404 但已有有效缓存时，仍将次年文件明确列出的跨年日期合入缓存，不丢失其他日期。404 只表示该源暂未提供文件，不能据此声称官方尚未公布。
- 对外 IPC 和缓存继续使用现有 `schemaVersion=1` 的内部年度结构，前后端共享同一快照。`sourceUrl` 保留上游该年度 `papers` 的首个政府公告链接；`version` 标识 `holiday-cn` / jsDelivr。
- 上游没有本应用的修订号。内部 `revision` 新年份从 1 开始，有效日期、标签或主公告来源变化时递增；仅 JSON 排序或检查日期变化不递增。`verifiedAt` 在新版本中表示本地下载并通过结构校验的日期，不是人工逐项核实官方公告的声明。
- `master` 为可变分支，CDN 存在缓存延迟；不承诺公告发布后即时同步，也不能用本地递增修订号证明上游内容的发布时间或新旧先后。

## 缓存、限频与失败保护

启动先读内置兜底与有效本地缓存，不等待网络。自动检查（包括失败）持久化限频至少 24 小时；手动检查可重试，但不保证绕过 CDN 缓存。

固定主机，不跟随重定向；单响应最多 256 KiB，整个下载批次总期限 15 秒。404 年份仍保持缺失或继续使用旧缓存；网络异常、其他 HTTP 错误、超时、非法 JSON、校验失败或事务失败保留整批原有效数据。网络请求不持有任务数据库锁。

年度缓存及成功状态事务提交，失败不清空旧数据。兼容已有有效年度缓存，忽略旧版自有索引元信息；首次切换来源时重置旧源的联网时间与错误，避免被旧源失败留下的 24 小时限频阻塞，之后持久化新来源的限频。不删除用户数据库，也不将旧元信息中的路径用于请求。数据源未提供的年份不预测调休。

## 内置兜底与开发验证

`data/holidays/2026.json` 是客户端内置兜底，不是线上更新源。人工修改内置文件时核对整份官方通知、来源与日期，保持内部结构有效并提高修订号。修改客户端内置兜底需要重新构建客户端；CDN 年度更新无需发布新安装包。

```powershell
$env:TMP=$env:PI_SCRATCH_DIR
$env:TEMP=$env:PI_SCRATCH_DIR
node --experimental-strip-types scripts/validate-holidays.mjs
node --experimental-strip-types --test src/*.test.mjs
npm.cmd run build
$env:PATH="$env:USERPROFILE\.cargo\bin;$env:PATH"
cargo test --manifest-path .\src-tauri\Cargo.toml
# 显式联网测试：使用生产下载器和内存数据库，不触碰真实用户数据
cargo test --manifest-path .\src-tauri\Cargo.toml live_jsdelivr_download -- --ignored --nocapture
```

联网测试确认实际 CDN JSON 可被生产下载器解析、2026 逐日工作日等价、次年覆盖及缓存重载；默认离线测试覆盖内容变化、跨年、缺口、限频、失败与事务保护。只完成模拟下载不代表真实 CDN 已验收。不把合成测试日期写入内置数据。

## 数据行为边界

缺失年份的工作时间暂按用户每周设置；法定工作日重复规则要求从起点至目标日期涉及的每一年都有覆盖，缺口不作推测。补齐后恢复未落地的规则推演，不移动或删除已保存任务块、单次执行结果及历史。

节气表目前只覆盖 2026 年；此更新流程不承诺未来年份节气显示，也不新增跨年节气算法。
